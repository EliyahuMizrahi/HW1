     python3 simulator.py --workload sample.csv --algo fcfs   (or sjf, rr, priority, mlfq)


Design decisions

Round Robin: quantum 4.

Priority:
  - lower number = higher priority
  - non-preemptive
  - aging: effective priority = priority - (time waited // 5)
  - ties go to the earlier arrival, then file order

MLFQ:
  - 3 queues: Q0 quantum 4, Q1 quantum 8, Q2 quantum 16
  - new processes start in Q0, and each queue is round robin
  - using the full quantum without finishing drops it a level (Q2 stays in Q2)
  - giving up the CPU early for I/O keeps it at the same level (optional
    5th "io" column, not used in my workloads)
  - a new arrival preempts anything running from Q1 or Q2
  - every 50 time units everything is boosted back to Q0
